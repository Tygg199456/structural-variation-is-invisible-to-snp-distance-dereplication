# Structural variation is invisible to SNP-distance dereplication

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23342892.svg)](https://doi.org/10.5281/zenodo.23342892)

**the reference strain of *Yersinia pestis* merges with its own attenuated derivative**

Analysis code, derived tables and figure scripts for the manuscript.

The study maps public *Y. pestis* assemblies to a single reference, calls variants,
dereplicates by SNP distance, and shows that three measurements built this way fail
silently: quality metrics become divergence filters, the distance is blind to
structural variation, and absence relative to the reference has unknown polarity.
A second-reference replication of the dereplication result is included
(`results/ref2/`).

## Reproduction boundary — read this before trying to re-run everything

Two different things are reproducible from this archive, and they cost very different
amounts of compute.

1. **From the archived derived tables to every figure and every reported number** —
   runs locally in minutes, no downloads, no cluster. This is what most readers want,
   and it is the path documented in `docs/REPRODUCE.md`.
   ```bash
   python3 figures/scripts/prep_figure_data.py     # rebuilds results/figures/*.csv
   for f in figures/scripts/fig[1-6]*.R; do Rscript "$f"; done
   ```

2. **From public accessions to the derived tables** — the full pipeline. This requires
   ~157 GB of per-genome variant calls, several CPU-days, a bakta database
   (39,401,553,410 bytes) and the NCBI Datasets CLI. The raw assemblies, the per-sample
   `snippy` output and the bakta database are **not** archived here; they are
   regenerable from `config.yaml` plus the accessions listed in the manuscript's
   Table S2. Budget for it: this is not a laptop job.

`results/numbers.json` contains one JSON object per analysis run: the script name, a UTC
timestamp and the numbers that run computed. `docs/NUMBER_REGISTRY.md` maps every number
printed in the manuscript's Results to the file and the computation behind it.

## Data sources

No new sequence data were generated. All genome assemblies are public NCBI records; the
reference is CO92 (`GCF_000009065.1`) and the outgroups are `GCA_000047365.1` and
`GCF_000016945.1`. The second-reference replication uses *Y. pestis* Antiqua
(`GCF_000013825.1`). Accessions for every analysed assembly are in the manuscript's
Supplementary Table S2.
